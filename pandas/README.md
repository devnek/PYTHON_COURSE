# 🐼 Pandas — Complete Course

A comprehensive, hands-on Pandas course spanning 10 chapters — from the very basics to a full data-analysis project.

## 📋 Course Syllabus

| # | Notebook | Topics |
|---|----------|--------|
| 1 | [Pandas Fundamentals](01_pandas_fundamentals.ipynb) | Series, DataFrame creation, viewing data, index management |
| 2 | [Reading & Writing Data](02_reading_writing_data.ipynb) | CSV, Excel, JSON, clipboard, URLs, encoding, large files |
| 3 | [Selecting & Filtering](03_selecting_filtering_data.ipynb) | `.loc`, `.iloc`, boolean masks, `.query()`, `.isin()`, `.str.contains()` |
| 4 | [Data Cleaning](04_data_cleaning_transformation.ipynb) | Missing data, duplicates, dtype conversion, `.str` accessor, `apply`/`map`, binning |
| 5 | [GroupBy & Aggregation](05_groupby_aggregation.ipynb) | `groupby`, `.agg()`, named aggs, `transform` vs `apply`, `.filter()` |
| 6 | [Merging & Joining](06_merging_joining_concatenation.ipynb) | `pd.concat`, `pd.merge` (all join types), suffixes, validation |
| 7 | [Reshaping Data](07_reshaping_pivot_melt_stack.ipynb) | `pivot_table`, `melt`, `stack`/`unstack`, `crosstab` |
| 8 | [Time Series](08_time_series_analysis.ipynb) | `DatetimeIndex`, resampling, rolling windows, `.shift()`, `.dt` accessor |
| 9 | [Performance Tips](09_performance_best_practices.ipynb) | Vectorization benchmarks, memory optimization, method chaining, anti-patterns |
| 10 | [Data Analysis Project](10_data_analysis_project.ipynb) | Full e-commerce analysis workflow with synthetic data |

## 🚀 Getting Started

### Prerequisites

```bash
pip install pandas numpy openpyxl
```

### Running the Notebooks

```bash
cd python_course/pandas
jupyter notebook
```

Or use **JupyterLab**:

```bash
pip install jupyterlab
jupyter lab
```

## 📖 How to Use This Course

1. **Work through chapters in order** — each chapter builds on previous concepts
2. **Run every code cell** — hands-on practice is essential
3. **Experiment!** — modify the code, try different parameters
4. **Chapter 10** is a capstone project that ties everything together

## 🎯 Learning Outcomes

By the end of this course you will be able to:

- Create and manipulate Series and DataFrames
- Read/write data in multiple formats (CSV, Excel, JSON)
- Select, filter, and slice data efficiently
- Clean messy real-world data (missing values, duplicates, type issues)
- Perform powerful GroupBy aggregations
- Merge multiple tables using SQL-style joins
- Reshape data between wide and long formats
- Analyze time series data with resampling and rolling windows
- Write performant Pandas code and avoid common pitfalls
- Execute a complete data analysis workflow from raw data to insights
