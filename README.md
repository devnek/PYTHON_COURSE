# Python: Zero to Mid-Level Mastery 🐍

A hands-on, phase-wise guide from Python fundamentals to intermediate concepts using interactive Jupyter Notebooks—**100% native standard library with zero external dependencies**.

---

## 📖 Course Overview

This curriculum covers 16 chapters structured across 4 progressive phases. Each notebook is packed with concept explanations, runnable code snippets, Pythonic tricks, and hands-on exercises.

### 🟢 Phase 1: Python Foundations
Core syntax, numbers, strings, and conditional logic.
- **Chapter 1:** [Variables, Data Types & Print](Ch01_Variables_and_DataTypes.ipynb) — Variables, dynamic typing, f-string formatting, and truthiness.
- **Chapter 2:** [Numbers and Math Operations](Ch02_Numbers_and_Math.ipynb) — Arithmetic, `divmod()`, chained comparisons, and the native `math` module.
- **Chapter 3:** [Strings: Deep Dive & Tricks](Ch03_Strings_DeepDive.ipynb) — Slicing, string methods, reversing tricks, translations, and formatting.
- **Chapter 4:** [Booleans and Conditional Logic](Ch04_Booleans_and_Conditionals.ipynb) — Truth values, ternary operators, short-circuit evaluation, and `match-case`.

### 🟡 Phase 2: Data Structures Mastery
Deep dive into native data structures with an emphasis on performance and idioms.
- **Chapter 5:** [Lists: The Complete Guide](Ch05_Lists_Complete_Guide.ipynb) — In-place operations, slicing tricks, flattening, transposing, chunking, and sorting.
- **Chapter 6:** [Tuples and Named Tuples](Ch06_Tuples_and_NamedTuples.ipynb) — Immutability, unpacking tricks, star expressions, and `collections.namedtuple`.
- **Chapter 7:** [Dictionaries: The Complete Guide](Ch07_Dictionaries_Complete_Guide.ipynb) — Safe access, dict comprehensions, merge operators (`|`), and grouping.
- **Chapter 8:** [Sets and Frozen Sets](Ch08_Sets_and_FrozenSets.ipynb) — Set operations, deduplication patterns, and immutable `frozenset`.

### 🟠 Phase 3: Control Flow & Functions
Writing expressive, efficient, and resilient code.
- **Chapter 9:** [Loops and Iteration Tricks](Ch09_Loops_and_Iteration.ipynb) — `enumerate()`, `zip()`, walrus operator (`:=`), `for...else`, and sliding windows.
- **Chapter 10:** [Functions: Basics to Advanced](Ch10_Functions_Mastery.ipynb) — `*args`/`**kwargs`, lambda functions, LEGB scope rules, and first-class functions.
- **Chapter 11:** [Comprehensions and Generators](Ch11_Comprehensions_and_Generators.ipynb) — List/dict/set comprehensions, lazy generators, and pipelines.
- **Chapter 12:** [Error Handling and Exceptions](Ch12_Error_Handling.ipynb) — `try-except-else-finally`, custom exceptions, and context managers.

### 🔴 Phase 4: Intermediate Python
Building robust programs with native modules and OOP.
- **Chapter 13:** [File I/O and Data Serialization](Ch13_File_IO_and_Serialization.ipynb) — File operations, `pathlib`, native `json`, `csv`, and directory management.
- **Chapter 14:** [Object-Oriented Programming](Ch14_OOP_Complete_Guide.ipynb) — Classes, inheritance, magic/dunder methods, properties, and `@dataclass`.
- **Chapter 15:** [Decorators and Closures](Ch15_Decorators_and_Closures.ipynb) — Closures, wrapper functions, `@wraps`, `@lru_cache`, and custom decorators.
- **Chapter 16:** [Standard Library Power Tools](Ch16_Standard_Library_PowerTools.ipynb) — `collections`, `itertools`, `functools`, `datetime`, `re` (regex), and `secrets`.

## 🚀 Getting Started

No `pip install` required! Simply clone the repository and open the notebooks in your favorite editor:

```bash
git clone https://github.com/devnek/PYTHON_COURSE.git
cd PYTHON_COURSE
```

Run using **Jupyter Notebook**, **JupyterLab**, or **VS Code**:
```bash
jupyter notebook
```
